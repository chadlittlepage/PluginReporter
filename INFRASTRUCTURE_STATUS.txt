=====================================================
TROUBLESHOOTING
=====================================================

If builds fail:
  1. Check GitHub Actions tab for errors
  2. Verify Xcode schemes are shared
  3. Check fastlane/Fastfile for correct paths
  4. Ensure Sentry SDK is in all targets

If Sentry not reporting:
  1. Check DSN is correct in app files
  2. Verify import Sentry is present
  3. Check Sentry dashboard for events
  4. Enable debug mode: options.debug = true

If Fastlane errors:
  1. Verify xcode-select path
  2. Check scheme names match
  3. Ensure project path is correct
  4. Run: fastlane --version

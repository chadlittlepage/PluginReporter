Importing from iLok License Manager

Bulk import your plugin licenses in seconds

Overview

Plugin Reporter can import license information directly from iLok License Manager's CSV export feature. This powerful integration allows you to:

  • Import hundreds of licenses at once
  • Automatically match licenses to your installed plugins
  • Save hours of manual data entry
  • Keep your license vault synchronized with iLok

💡 One-Time Setup

This is typically a one-time process. Once imported, you can update individual licenses as needed in the License Vault.

Step 1: Export from iLok License Manager

First, you'll need to export your license data from iLok License Manager:

  1. Open iLok License Manager
    • Launch the iLok License Manager application
    • Make sure you're signed in to your iLok account
  2. View Your Licenses
    • Make sure you're viewing your licenses (not a specific iLok device)
    • You should see all your licenses in the main window
  3. Customize Columns (Optional)
    • Right-click on the table header
    • Check the columns you want to export
    • Recommended: Product Name, Publisher, Serial Number, Location, Type
  4. Export to CSV
    • Look for the "Export CSV" button (toolbar or File menu)
    • Click it and save the file
    • Choose a memorable location (like Desktop or Downloads)

⚠️ Common Issue

Make sure you're exporting the license list, not device information or account settings. The export should contain plugin/software names and publishers.

Step 2: Import to Plugin Reporter

Now import the CSV file into Plugin Reporter:

  1. Open Settings
    • Press ⌘, or go to Plugin Reporter → Settings
  2. Navigate to License Import
    • Scroll down to the "License Import" section
    • Click the "Import from iLok" button
  3. Follow the Import Wizard
    • Read the step-by-step instructions
    • Click "Select CSV File"
    • Choose the file you exported from iLok License Manager
  4. Wait for Processing
    • Plugin Reporter will parse the CSV file
    • It will match licenses to your installed plugins
    • This usually takes a few seconds
  5. Review Results
    • You'll see a detailed import summary
    • Total licenses found
    • Successfully matched plugins
    • Unmatched licenses (explained below)

Understanding Import Results

Successfully Matched

These licenses were automatically matched to plugins in your library:

  • License data populated in the License Vault
  • Serial numbers, activation tracking, and notes added
  • Ready to use immediately

Unmatched Licenses

Some licenses may not match to installed plugins. This is normal and happens when:

  • Plugin not installed - You own the license but haven't installed the plugin
  • Name mismatch - iLok uses different product names than the installed plugin
  • Bundle licenses - The license is for a bundle, but individual plugins are installed
  • Different publisher names - Publisher name differs between iLok and plugin metadata

💡 What to Do with Unmatched Licenses

Review the unmatched list and:

  • Manually add license info for installed plugins that didn't match
  • Keep a note of licenses for plugins you might install later
  • Re-import after installing new plugins

How Matching Works

Plugin Reporter uses a smart 3-stage matching algorithm:

Stage 1: Exact Match

  • Matches by Product Name + Publisher
  • Example: "FabFilter Pro-Q 3" + "FabFilter" ✓
  • Most accurate, highest priority

Stage 2: Name-Only Match

  • Matches by Product Name only (case-insensitive)
  • Example: "Pro-Q 3" → finds "FabFilter Pro-Q 3" ✓
  • Used when publisher name differs

Stage 3: Fuzzy Match

  • Matches by substring contains
  • Example: "Waves SSL" → finds "SSL G-Master Buss Compressor" ✓
  • Catches abbreviated or partial names

Data Merging

If you've already added license information manually, Plugin Reporter intelligently merges the data:

Preserved (Not Overwritten)

  • Existing serial numbers
  • Manually entered passwords
  • Purchase dates
  • Invoice numbers
  • Custom notes
  • Vendor URLs

Added (If Missing)

  • Serial numbers from iLok
  • Activation tracking
  • Location and type info

Appended

  • Notes - iLok import info is added to existing notes

✅ Safe to Re-Import

You can safely re-import the same file multiple times. Your manual edits won't be lost!

Troubleshooting

Import Failed: "No Product Name column found"

Cause: The CSV doesn't have a Product Name column or is in the wrong format.

Solution:

  • Make sure you exported the license list, not device info
  • Try re-exporting from iLok with default columns
  • Check that the file is actually a CSV (not Excel or PDF)

Import Failed: "Invalid CSV format"

Cause: The file is empty or corrupted.

Solution:

  • Open the CSV in a text editor to verify it has content
  • Re-export from iLok License Manager
  • Make sure the file wasn't modified after export

Many Licenses Show as "Unmatched"

Cause: Product names in iLok don't match installed plugin names.

Solution:

  • This is normal - not all licenses will match
  • Review the unmatched list to identify false negatives
  • Manually add license info for important plugins
  • Install missing plugins, then re-import

Import Seems Slow

Cause: Large license libraries take longer to process.

Expected Times:

  • 100 licenses: ~1 second
  • 500 licenses: ~3 seconds
  • 1000+ licenses: ~5-10 seconds

Re-Importing After Changes

You can re-import at any time to update license data:

When to Re-Import

  • After purchasing new plugins
  • After installing previously owned plugins
  • When license information changes in iLok
  • After updating to new plugin versions

What Happens on Re-Import

  1. New licenses are imported
  2. Existing data is preserved (merged, not replaced)
  3. Updated activation counts are reflected
  4. No duplicate entries are created

Privacy & Security

What's Included

  • Serial numbers and license keys
  • Product names and publishers
  • Activation counts and locations
  • License types and versions

What's NOT Included

  • Passwords (not in iLok CSV exports)
  • iLok account credentials
  • Personal account information
  • Payment information

Data Storage

  • All imported data stored locally on your Mac
  • Optional iCloud sync via CloudSyncStorage
  • No third-party servers involved
  • Complete control over your data

Tips for Best Results

✅ Do This

  • Include all columns when exporting from iLok
  • Keep CSV file for future re-imports
  • Review unmatched licenses to catch false negatives
  • Manual cleanup after import for perfect accuracy
  • Create backup after importing (Settings → Export Archive)

⚠️ Avoid This

  • Don't edit the CSV file before importing
  • Don't export device-specific views (export all licenses)
  • Don't import the same file repeatedly without purpose
  • Don't delete the CSV after first import (keep for re-importing later)

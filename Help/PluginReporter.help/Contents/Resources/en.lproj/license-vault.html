License Vault

Secure storage for your plugin licenses and credentials

Overview

Plugin Reporter's License Vault provides a secure, centralized location to store all your plugin license information, serial numbers, activation codes, and account credentials. Never lose a license key again!

What You Can Store

  • Serial Numbers - License keys and registration codes
  • Account Credentials - Email addresses and passwords (encrypted in macOS Keychain)
  • Activation Tracking - Monitor how many seats you've used
  • Purchase Information - Purchase dates and invoice numbers
  • Vendor Links - Quick access to manufacturer websites, account portals, and support pages
  • Notes - Additional information or reminders

Accessing the License Vault

There are two ways to access license information for a plugin:

Method 1: Detail Panel

  1. Select a plugin in the main table
  2. Open the Detail Panel (if not already visible)
  3. Click the "License" tab at the top
  4. You'll see the license information for that plugin

Method 2: Direct Access

You can also access license information from:

  • Right-click menu on any plugin
  • Double-clicking a plugin (if configured in preferences)

License Column Quick View

Plugin Reporter displays license status directly in the main plugin table for quick reference:

What the License Column Shows

  • "Serial" - Plugin has a serial number or license key stored
  • "iLok" - License managed via iLok License Manager (manually added or imported)
  • Blank - No license information stored yet

Benefits

  • See at a glance which plugins have licenses stored
  • Identify license type without opening the License tab
  • Sort and filter by license status
  • Included in all exports (CSV, PDF, printed reports)

💡 Pro Tip

Use the License column to quickly identify plugins that still need license information added. Blank entries show plugins where you haven't stored license data yet.

Adding License Information

To add license information for a plugin:

  1. Navigate to the plugin's License tab (see above)
  2. Click "Add License Info"
  3. Fill in the relevant fields:
    • Serial Number or License Key
    • Account email
    • Password (stored securely in macOS Keychain)
    • Activation tracking (seats used/total)
    • Purchase date and invoice number
    • Vendor URLs (website, account portal, support)
    • Notes
  4. Click "Done" to save

💡 Tip: Import from iLok

If you use iLok License Manager, you can import all your licenses at once! See Importing from iLok for details.

Editing License Information

To edit existing license information:

  1. Open the plugin's License tab
  2. Click "Edit"
  3. Make your changes
  4. Click "Done" to save

All changes are saved immediately and synced to iCloud (if enabled).

Security Features

Keychain Integration

Passwords are stored using macOS Keychain, the same secure system used by Safari, Mail, and other Apple apps. This means:

  • Passwords are encrypted by the system
  • Protected by your Mac's login password
  • Never stored in plain text
  • Backed up via iCloud Keychain (if enabled)
  • Same security level as your banking credentials

Archive Encryption

When you export an archive, you can choose to encrypt it with AES-256-GCM encryption. Encrypted archives include:

  • All license data (serial numbers, etc.)
  • Keychain passwords
  • Complete protection with your chosen password

Privacy

  • All data stays local or in your personal iCloud
  • No third-party servers
  • You have complete control over your data

Common Use Cases

Computer Migration

Scenario: Moving to a new Mac

  1. Export encrypted archive from old Mac
  2. Transfer archive to new Mac
  3. Import archive
  4. All license info restored instantly!

License Recovery

Scenario: "Where did I put that serial key?!"

  1. Open Plugin Reporter
  2. Find the plugin
  3. Click License tab
  4. Copy serial number - done!

Activation Management

Scenario: Need to deactivate before reinstalling

  1. Check License tab to see activation count
  2. Plan deactivations if at limit
  3. Use account portal link to manage online

Team Collaboration

Scenario: Studio with multiple users

  1. Store shared license info centrally
  2. Export individual license files if needed
  3. Track which plugins need team licenses

Tips & Best Practices

✅ Do This

  • Add license info as soon as you purchase a plugin
  • Create regular encrypted backups
  • Use the iLok import feature to bulk-add licenses
  • Keep vendor URLs up to date
  • Use Notes field for upgrade eligibility info
  • Track activation limits to avoid surprises

⚠️ Important

  • Always export encrypted archives, not unencrypted ones (passwords aren't included in unencrypted exports)
  • Don't share unencrypted archives - they contain serial numbers
  • Use strong passwords for Keychain items
  • Keep your archive passwords in a safe place

Adding License Information

Step-by-step guide to storing your plugin licenses

Quick Start

Adding license information is simple:

  1. Select a plugin in the main table
  2. Open the Detail Panel → License tab
  3. Click "Add License Info"
  4. Fill in the fields
  5. Click "Done" to save

Detailed Instructions

Step 1: Navigate to License Tab

  1. Select the plugin you want to add license info for
  2. The Detail Panel should appear on the right
    • If hidden, click the detail panel toggle button
  3. Click the "License" tab at the top
    • You'll see "Metadata" and "License" tabs
    • Click "License"

Step 2: Create New License Entry

If no license info exists yet, you'll see:

  • A key icon
  • "No license information stored" message
  • "Add License Info" button

Click the "Add License Info" button to begin.

Step 3: Fill in License Details

The license form will appear with several sections. Fill in what you have:

Serial Number

  • Enter your license key or serial number
  • This is usually the most important field
  • Copy from your purchase email or plugin account

Account Credentials

  • Email - The email address for your plugin account
  • Password - Stored securely in macOS Keychain
    • Encrypted automatically
    • Same security as Safari passwords

Activation Tracking

  • Activations Used - How many computers/seats you've activated
  • Max Activations - Total allowed (e.g., 3)
  • Activation Code (optional) - Some plugins have separate activation codes

Purchase Information

  • Purchase Date - When you bought the plugin
  • Invoice Number (optional) - For warranty/upgrade tracking

Vendor Links

  • Manufacturer Website - Company homepage
  • Account Portal - Where you manage your license online
  • Support - Help/support page

Notes

  • Free-form text area
  • Add installation notes, upgrade history, etc.
  • Helpful for remembering special circumstances

Step 4: Save the License

Click "Done" to save. The information is:

  • Saved immediately to local storage
  • Synced to iCloud (if enabled)
  • Included in archive backups

Field-by-Field Guide

Serial Number / License Key

What it is: The unique code that proves you own the plugin.

Where to find it:

  • Purchase confirmation email
  • Plugin manufacturer's account portal
  • Inside the plugin installer
  • iLok License Manager (for iLok-protected plugins)

Examples:

  • XXXX-XXXX-XXXX-XXXX (standard format)
  • ABC123-DEF456-GHI789 (alphanumeric)
  • 1234567890ABCDEF (long code)

Account Email

What it is: The email address you used to create your account with the vendor.

Why store it:

  • Required for password resets
  • Needed to access account portals
  • Helps identify which account has the license

Password

What it is: Your vendor account password.

Security:

  • Stored in macOS Keychain (encrypted)
  • Never visible in plain text (shows ••••••••)
  • Protected by your Mac login password
  • Only included in encrypted archive exports

Copy feature: Click the copy button to paste password when logging in.

Activations Used / Max Activations

What it tracks: How many computers you've activated the plugin on.

Example:

  • Used: 2
  • Max: 3
  • Meaning: You can install on 1 more computer

Warning indicator: Plugin Reporter shows a warning when you're at the limit.

Activation Code

What it is: Some plugins require a separate code for activation (different from serial number).

Examples:

  • Challenge/response codes
  • Machine-specific activation codes
  • Offline activation codes

Purchase Date

What it is: When you purchased the plugin.

Why store it:

  • Track upgrade eligibility
  • Warranty tracking
  • Tax/expense records

Invoice Number

What it is: Receipt or invoice number from your purchase.

Why store it:

  • Proof of purchase
  • Warranty claims
  • Upgrade verification

Vendor Links

Manufacturer Website:

  • Company homepage (e.g., https://www.fabfilter.com)
  • Quick access to product info

Account Portal:

  • Where you manage licenses online
  • Example: https://account.fabfilter.com
  • Useful for activations/deactivations

Support:

  • Help or support page
  • Quick access when you need help

Notes

What to include:

  • Installation notes ("Requires iLok 3")
  • Upgrade history ("Upgraded from v2 on 2024-06-15")
  • Special circumstances ("Educational license, renews annually")
  • Where files are stored ("License file in Dropbox")
  • Bundle info ("Part of FabFilter Total Bundle")

Editing Existing Licenses

To update license information:

  1. Open the plugin's License tab
  2. Click "Edit"
  3. Modify any fields
  4. Click "Done" to save

All changes are saved immediately and the "Last Modified" timestamp is updated.

Copying License Information

When viewing (not editing) a license, you can quickly copy:

  • Serial Number - Click the copy button next to it
  • Email - Click the copy button
  • Password - Click the copy button (copies hidden password)
  • Activation Code - Click the copy button

A green "Copied to clipboard" message appears briefly to confirm.

Deleting License Information

To remove license info for a plugin:

  1. Open the License tab
  2. Scroll to the bottom
  3. Click "Delete License Info" (red button)
  4. Confirm deletion

⚠️ Warning

This permanently deletes the license info (including Keychain password). Make sure you have the information backed up if needed!

Tips for Organization

Add Licenses Right Away

When you purchase a plugin:

  1. Install it
  2. Immediately add license info
  3. You'll never lose the serial number

Use Consistent Formatting

  • Keep serial numbers in ORIGINAL format (don't add/remove dashes)
  • Use full URLs for vendor links (include https://)
  • Be consistent with date formats

Fill in What You Have

  • Not all fields are required
  • At minimum, store the serial number
  • Add more info as you find it

Regular Backups

  • Create encrypted archives regularly
  • Store backups in safe locations
  • Test restore process occasionally

Common Scenarios

Educational/NFR Licenses

For educational or NFR (Not For Resale) licenses:

  • Add "(EDU)" or "(NFR)" to the notes
  • Include expiration date if applicable
  • Note any usage restrictions

Subscription Licenses

For subscription-based plugins:

  • Note renewal date in Notes field
  • Include subscription tier if relevant
  • Add payment frequency (monthly/annual)

Bundle Licenses

For plugin bundles:

  • You can create one license entry or separate ones
  • If one serial covers multiple plugins, note which ones
  • Use Notes to link related plugins

Bulk Import Alternative

If you have many licenses to add, consider:

  • Importing from iLok - Import hundreds at once
  • CSV template (future feature) - Import from spreadsheet

Manual entry is best for:

  • Single plugins
  • Non-iLok licenses
  • Custom/detailed information

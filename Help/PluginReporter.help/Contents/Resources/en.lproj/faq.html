Frequently Asked Questions

Quick answers to common questions

General Questions

What is Plugin Reporter?

Plugin Reporter is a macOS application that helps you catalog, organize, and manage your audio plugin library. It scans your system for AU, VST, VST3, AAX, CLAP, and LV2 plugins, allowing you to rate, tag, add notes, and organize them efficiently.

Is Plugin Reporter free?

Check the App Store or the official website for current pricing and licensing information.

What versions of macOS are supported?

Plugin Reporter requires macOS 13.0 (Ventura) or later. It's optimized for both Intel and Apple Silicon Macs.

Does Plugin Reporter work on iOS/iPadOS?

Yes! Plugin Reporter is available for iPad and iPhone. The iOS version includes most macOS features with a touch-optimized interface.

Will Plugin Reporter slow down my system?

No. Plugin Reporter is highly optimized and uses minimal system resources. Scanning runs in the background and won't interfere with your music production work.

Scanning & Detection

Why aren't all my plugins showing up?

Common reasons:

  • Plugins are installed in non-standard locations (use custom scan paths in Settings)
  • Scan hasn't completed yet (check status bar)
  • Plugins are in a format not yet supported
  • Cache needs to be cleared (Settings > Scanning > Clear Cache)

How do I scan custom plugin folders?

  1. Open Settings (⌘,)
  2. Go to the Scanning section
  3. Click Add Custom Path
  4. Navigate to your custom plugin folder
  5. Click Scan Now

How long does scanning take?

Scanning speed depends on how many plugins you have:

  • 50-100 plugins: ~5-10 seconds
  • 200-500 plugins: ~15-30 seconds
  • 1000+ plugins: ~1-2 minutes

Can I scan while I'm working?

Yes! Scanning runs in the background with minimal CPU usage. You can continue using your DAW or other apps while Plugin Reporter scans.

Does Plugin Reporter scan my DAW plugins automatically?

Yes. Plugin Reporter scans the standard plugin locations used by all major DAWs. If your DAW uses custom locations, you can add them manually in Settings.

Why do some imported projects show 0 plugins?

This can happen if:

  • The project genuinely has no plugins (only audio/MIDI clips)
  • The project file format is newer than Plugin Reporter supports (update the app)
  • The project file is corrupted or incomplete
  • Plugins are referenced in an unsupported way

Can I import multiple projects at once?

Yes! Select multiple project files when importing, or drag a whole folder onto Plugin Reporter. Projects are processed in parallel for maximum speed.

Do imported projects modify my original files?

No. Plugin Reporter only reads project files - it never modifies them. Your original projects are completely safe.

Ratings, Tags & Notes

Can I rate multiple plugins at once?

Yes! Select multiple plugins (using ⌘+click or Shift+click) and press 1-5 to rate them all at once.

Are ratings synced between Macs?

Yes, if you enable iCloud Sync in Settings. All ratings, tags, and notes sync automatically across your Macs.

Can I export my ratings?

Yes. Use File > Export and choose to include ratings in the exported file (CSV, JSON, HTML, or PDF).

What's the difference between tags and styles?

  • Style: The plugin's category (Effect, Instrument, Reverb, etc.) - detected automatically from plugin metadata
  • Tags: Your personal organization system - you create and assign these (e.g., "Vocals", "Master Bus", "Favorites")

How many tags can I add to a plugin?

There's no limit! Add as many tags as you need to organize your plugins effectively.

Data & Privacy

Does Plugin Reporter collect any data?

Plugin Reporter respects your privacy:

  • All plugin data stays on your Mac (or in your personal iCloud)
  • No plugin lists are sent to external servers
  • Anonymous crash reports may be collected (can be disabled in Settings)
  • No tracking, analytics, or advertising

Where is my data stored?

Plugin Reporter stores data in:

  • ~/Library/Containers/com.chadlittlepage.PluginReporter/ - Main app data
  • iCloud Key-Value Store (if iCloud Sync is enabled)
  • Archives you create manually (.pluginreporter files)

Can I export all my data?

Yes! Use Settings > Backup & Restore > Export Archive to create a complete backup of all your data.

Is my data encrypted?

  • Local data is protected by macOS file permissions
  • iCloud data is encrypted in transit and at rest by Apple
  • Archives can be encrypted with AES-256 if you choose a password

Performance

Plugin Reporter is running slowly. What can I do?

Try these steps:

  1. Clear the scan cache (Settings > Scanning > Clear Cache)
  2. Close other apps to free up RAM
  3. Check for app updates
  4. Restart Plugin Reporter
  5. If you have 5000+ plugins, consider filtering to reduce the displayed list

Scanning is taking too long

If scanning seems stuck:

  • Check if you have plugins in network drives (these scan slower)
  • Some plugins may be corrupted and hang during scanning (check Console.app)
  • Try excluding problematic folders in Settings > Scanning > Excluded Paths

The app is using too much disk space

Plugin Reporter is very lightweight (typically under 100 MB including cache). If disk usage is high:

  • Clear the cache (Settings > Scanning > Clear Cache)
  • Delete old archives you no longer need
  • Check if playlists contain large amounts of data

Exporting

What export formats are available?

  • CSV: Import into Excel, Google Sheets, Numbers
  • JSON: For developers and automation scripts
  • HTML: Beautiful standalone web page
  • PDF: Professional printable reports

Can I customize what's included in exports?

Yes! The export dialog lets you choose:

  • Which columns to include
  • Whether to include ratings, tags, notes
  • Filtered vs. all plugins
  • Sort order

Can I schedule automatic exports?

Not currently, but you can use macOS Automator or shortcuts to automate exports using AppleScript.

Troubleshooting

Plugin Reporter won't launch

Try these steps in order:

  1. Restart your Mac
  2. Check for macOS updates
  3. Reinstall Plugin Reporter from the App Store
  4. Check Console.app for crash logs
  5. Contact support with crash logs

I accidentally deleted all my ratings!

Don't panic:

  • If you have iCloud Sync enabled, turn it off and back on to restore from iCloud
  • If you have a recent archive, import it (Settings > Backup & Restore)
  • Check Time Machine backups for your Plugin Reporter container

Plugins are showing as "missing" but they're installed

This can happen when:

  • Plugin names don't match exactly (e.g., "Reverb" vs "Reverb Pro")
  • Plugin format has changed (AU vs VST)
  • Plugins were renamed after the project was created
  • Scan hasn't detected the newly installed plugin yet (try Force Rescan)

App is asking for permissions

Plugin Reporter needs:

  • File Access: To scan plugin folders
  • Full Disk Access: To scan system plugin directories (optional, for AAX/system plugins)

Grant these in System Preferences > Security & Privacy > Privacy.

Plugin Reporter is currently macOS-only. Windows/Linux support may be considered in the future based on demand.

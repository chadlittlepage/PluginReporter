Getting Started with Plugin Reporter

Your quick start guide

Welcome!

Plugin Reporter helps you manage your audio plugin library with ease. This guide will walk you through the basics and get you up and running in minutes.

First Launch

When you first launch Plugin Reporter, the app will automatically scan your system for installed audio plugins. This process may take a few moments depending on how many plugins you have installed.

Note: Plugin Reporter scans the standard macOS plugin locations:
  • ~/Library/Audio/Plug-Ins/Components (Audio Units)
  • ~/Library/Audio/Plug-Ins/VST (VST2)
  • ~/Library/Audio/Plug-Ins/VST3 (VST3)
  • /Library/Application Support/Avid/Audio/Plug-Ins (AAX)
  • ~/Library/Audio/Plug-Ins/CLAP (CLAP)
  • ~/.lv2 (LV2)

Understanding the Interface

Main Window

The Plugin Reporter interface consists of several key areas:

  1. Toolbar - Quick access to scanning, exporting, and view options
  2. Sidebar - Filter plugins by format, publisher, style, and ratings
  3. Plugin Table - Your main plugin list with sortable columns
  4. Detail Panel - View and edit information about selected plugins
  5. Search Bar - Quickly find plugins by name, publisher, or attributes

Basic Tasks

1. Scanning for Plugins

To manually scan for new plugins:

  1. Click the Scan button in the toolbar
  2. Wait for the scan to complete
  3. New plugins will appear in your list automatically
Tip: Plugin Reporter can automatically scan when you launch the app. Enable this in Preferences > Scanning.

2. Filtering Plugins

Use the sidebar to filter your plugin list:

  • Formats - Show only AU, VST3, AAX, etc.
  • Publishers - Filter by manufacturer
  • Styles - View by plugin category (Effect, Instrument, etc.)
  • Ratings - Show only your top-rated plugins

3. Rating Plugins

To rate a plugin:

  1. Select one or more plugins in the table
  2. Click the star icons in the detail panel
  3. Or right-click and choose Set Rating

4. Adding Tags

Organize plugins with custom tags:

  1. Select a plugin
  2. Click Add Tag in the detail panel
  3. Enter a tag name (e.g., "Vocals", "Master Bus", "Favorites")
  4. Press Return to save

5. Searching

The search bar at the top filters your plugin list in real-time. Search by:

  • Plugin name
  • Publisher/manufacturer
  • Style/category
  • Version number
  • Architecture (Intel, Apple Silicon)
Pro Tip: You can also search by format. Type "VST3" or "AU" to filter by plugin type.

To Import a Project:

  1. Choose File > Import DAW Project (or press ⌘I)
  2. Select one or more project files
  3. Plugin Reporter will extract the plugin list and show which plugins are used
  4. Missing plugins (not installed on your system) will be highlighted

You can also drag and drop project files directly onto the Plugin Reporter window!

Exporting Your Plugin List

Share your plugin inventory with others or keep records:

Export Formats

  • CSV - Import into Excel or Google Sheets
  • JSON - For developers and automation
  • HTML - Beautiful web page with your plugin list
  • PDF - Professional printable reports

To Export:

  1. Choose File > Export (or press ⌘E)
  2. Select your desired format
  3. Choose what to include (ratings, notes, tags, etc.)
  4. Click Export and choose a save location

Backup & Restore

Protect your ratings, tags, notes, and playlists with the Archive feature:

  1. Go to Settings > Backup & Restore
  2. Click Export Archive
  3. Choose whether to encrypt with a password (recommended)
  4. Save the .pluginreporter file to a safe location

To restore from a backup, click Import Archive and select your saved file.

Important: If you encrypt your archive, make sure to remember your password! There is no way to recover an encrypted archive without the password.

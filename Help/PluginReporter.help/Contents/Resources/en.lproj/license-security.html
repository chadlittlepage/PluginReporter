Security & Keychain

How your license data is protected

Overview

Plugin Reporter takes security seriously. Your license information - especially passwords - is protected using industry-standard encryption and Apple's built-in security frameworks.

🔒 Bank-Level Security

Passwords are stored using the same macOS Keychain system that protects your banking credentials in Safari, Mail, and other trusted apps.

macOS Keychain Integration

What is Keychain?

Keychain is Apple's secure password management system built into macOS. It:

  • Encrypts all passwords automatically
  • Requires your login password to access
  • Uses AES-256 encryption
  • Is maintained and updated by Apple
  • Has been battle-tested for decades

How Plugin Reporter Uses Keychain

When you save a password in the License Vault:

  1. Password is encrypted by macOS Keychain
  2. Stored in secure system-level storage
  3. Only accessible with your Mac login password
  4. Protected from unauthorized access
  5. Automatically backed up (if iCloud Keychain enabled)

Keychain Service Identifier

Plugin Reporter uses the service identifier:

com.chadlittlepage.PluginReporter.licenses

You can verify this in the Keychain Access app.

CloudSyncStorage

License metadata (everything except passwords) is stored in:

  • Local file storage
  • Optional iCloud Key-Value Store sync
  • Protected by macOS file permissions
  • Accessible only to Plugin Reporter

Archive Encryption

Two Types of Archives

Unencrypted Archives

  • Include serial numbers and license metadata
  • Do NOT include passwords (for security)
  • Useful for sharing plugin lists without sensitive data
  • Not recommended for backups containing licenses

Encrypted Archives (Recommended)

  • Include ALL license data including passwords
  • Encrypted with AES-256-GCM
  • Password-protected
  • Complete backup of your license vault

✅ Always Use Encrypted Archives

When backing up license data, always choose encryption. Unencrypted archives deliberately exclude passwords for your protection.

Encryption Details

Archive Encryption (AES-256-GCM)

Encrypted archives use:

  • Algorithm: AES-256-GCM
  • Key Derivation: PBKDF2 with 100,000 iterations
  • Salt: Random 16-byte salt per archive
  • Authentication: Built-in authentication tag (GCM mode)
  • Industry Standard: Used by governments and financial institutions

Keychain Encryption

macOS Keychain uses:

  • Algorithm: AES-256
  • Protection: Tied to your login password
  • Hardware: Can use Secure Enclave (on supported Macs)
  • Updates: Maintained by Apple security team

Access Control

Who Can Access Your License Data?

Passwords (Keychain)

  • You - When logged into your Mac
  • Plugin Reporter - Only with your Mac unlocked
  • Nobody else - Protected by macOS security

License Metadata

  • You - Full access
  • Plugin Reporter - Full access
  • Other apps - No access (sandboxed)
  • Other users - No access (file permissions)

When Locked

When your Mac is locked:

  • Keychain passwords are inaccessible
  • Files are protected by FileVault (if enabled)
  • Plugin Reporter cannot access sensitive data

iCloud Sync Security

What Syncs to iCloud

If iCloud sync is enabled:

  • License metadata (serial numbers, notes, etc.)
  • Stored in iCloud Key-Value Store
  • Encrypted in transit and at rest
  • Apple's standard iCloud security applies

What Does NOT Sync

  • Passwords - Only in Keychain (optionally via iCloud Keychain)
  • Passwords sync separately through iCloud Keychain (if enabled)
  • This is Apple's design for maximum security

iCloud Keychain

If you enable iCloud Keychain (separate from Plugin Reporter):

  • Keychain passwords sync across your Macs
  • End-to-end encrypted
  • Not accessible to Apple
  • Plugin Reporter passwords included automatically

Best Practices

For Maximum Security

✅ Recommended

  • Use strong Mac login password - Protects Keychain
  • Enable FileVault - Full-disk encryption
  • Create encrypted archives - Complete backups
  • Use strong archive passwords - 12+ characters, mixed case, numbers, symbols
  • Store archives securely - Password manager or encrypted drive
  • Enable iCloud Keychain - Sync passwords securely
  • Lock your Mac when away (Control-Command-Q)

Password Guidelines

For archive passwords:

  • Length: Minimum 12 characters (16+ recommended)
  • Complexity: Mix of uppercase, lowercase, numbers, symbols
  • Uniqueness: Don't reuse passwords
  • Storage: Use a password manager (1Password, LastPass, etc.)
  • Recovery: Store backup of password in safe location

⚠️ Important

Archive passwords cannot be recovered! If you forget the password, the encrypted archive cannot be opened. Store passwords safely!

Viewing Keychain Items

How to View in Keychain Access

  1. Open Keychain Access app (in /Applications/Utilities)
  2. Select "login" keychain in the left sidebar
  3. Search for: PluginReporter
  4. You'll see entries like: com.chadlittlepage.PluginReporter.licenses: {plugin-id}
  5. Double-click to view details
  6. Click "Show password" (requires Mac password)

Keychain Entry Details

Each password entry contains:

  • Service: com.chadlittlepage.PluginReporter.licenses
  • Account: Unique plugin ID (publisher_name)
  • Where: Login keychain
  • Access: Plugin Reporter only

Data Retention & Deletion

When You Delete a License

When you delete license info in Plugin Reporter:

  1. License metadata removed immediately
  2. Keychain password deleted automatically
  3. Changes sync to iCloud (if enabled)
  4. Data removed from future archives

When You Uninstall Plugin Reporter

If you uninstall the app:

  • Keychain items remain (safe default)
  • To fully remove, manually delete from Keychain Access
  • Or use Settings → Delete All Data before uninstalling

Complete Data Removal

To completely remove all license data:

  1. Open Keychain Access
  2. Search for "PluginReporter"
  3. Delete all matching items
  4. Delete CloudSyncStorage data
  5. Uninstall Plugin Reporter

Troubleshooting

Keychain Access Denied

Symptom: Plugin Reporter asks for Keychain access repeatedly.

Solution:

  1. Open Keychain Access
  2. Find Plugin Reporter password entries
  3. Right-click → Get Info
  4. Access Control tab
  5. Add Plugin Reporter to allowed apps

Password Not Saving

Symptom: Password doesn't appear after saving.

Solution:

  • Check Keychain Access for the entry
  • Verify you approved the Keychain permission
  • Restart Plugin Reporter
  • Check macOS System Preferences → Security

Cannot Decrypt Archive

Symptom: "Wrong password" error when importing archive.

Solutions:

  • Verify password (check caps lock, etc.)
  • Try the password you think it is
  • Check if you have password stored in password manager
  • If truly lost, archive cannot be recovered

Frequently Asked Questions

Q: Is my license data sent to any servers?

A: No. All data stays on your Mac and (optionally) your personal iCloud. Plugin Reporter has no servers and sends no data anywhere.

Q: Can the developer see my passwords?

A: No. Passwords are encrypted by macOS Keychain. Only you can access them with your Mac login password. The developer has no access to your data.

Q: What if I forget my archive password?

A: Encrypted archives cannot be recovered without the password. This is by design for security. Always store archive passwords safely!

Q: Are passwords included in iCloud sync?

A: Passwords sync separately via iCloud Keychain (if you have it enabled). License metadata syncs via Plugin Reporter's iCloud sync. Both are encrypted.

Q: Is it safe to share an archive with someone?

A: Only share encrypted archives if you trust the person with your serial numbers and passwords. Unencrypted archives don't contain passwords but do contain serial numbers.

Q: How do I backup my Keychain passwords?

A: Use Plugin Reporter's encrypted archive export. This includes both license data AND Keychain passwords in one secure file.

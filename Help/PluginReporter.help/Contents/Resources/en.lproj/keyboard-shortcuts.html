Filter Shortcuts

Access from Plugins → Filters menu:

Plugin Type Filters

  • AU, VST, VST3, AAX, CLAP, LV2, OBSOLETE
  • Toggle multiple types to view plugins of specific formats

Rating Filters

  • Filter by star ratings (1-5 stars)
  • Show only your favorite plugins

Style & Publisher Filters

  • Filter by plugin style (EQ, Compressor, Synth, etc.)
  • Filter by publisher/developer

Clear All Filters

  • Press X in Plugins → Filters menu
  • Resets all plugin filters to show everything

Playlist Filter Shortcuts

Access from Playlists → Filters menu:

Sort Options

  • Date Imported - Sort by when playlist was added
  • Name - Alphabetical sorting

Filter Options

  • Missing - Show only playlists with missing plugins
  • DAW Type - Filter by Logic Pro, Pro Tools, Ableton, etc.
  • Rating - Filter playlists by star rating

Clear Playlist Filters

  • Press X in Playlists → Filters menu
  • Resets all playlist filters

Pro Tips

Combine Filters for Powerful Searches

  • Use Type + Style filters together (e.g., "Show only VST3 Compressors")
  • Combine Rating + Publisher filters (e.g., "5-star Waves plugins")
  • Filter playlists by DAW Type + Missing to find specific issues

Quick Appearance Switching

  • Press ⌘⌥3 for instant Dark mode
  • Press ⌘⌥4 for Space theme (black background)
  • Press ⌘⌥1 to follow system appearance

Efficient Workflow

  • Start with ⌘R to scan plugins
  • Use ⌘⌥F to show filters panel
  • Apply filters to narrow down plugins
  • Press ⌘⇧E to export filtered results
  • Press X in Filters menu to reset and start fresh

Customizing Shortcuts

You can customize keyboard shortcuts for Plugin Reporter using macOS System Settings:

  1. Open System Settings → Keyboard → Keyboard Shortcuts
  2. Select App Shortcuts in the left sidebar
  3. Click the + button
  4. Choose Plugin Reporter from the Application dropdown
  5. Enter the exact menu title (e.g., "Scan for Plugins")
  6. Click in the Keyboard Shortcut field and press your desired key combination
  7. Click Add
Note: The menu title must match exactly, including capitalization and punctuation. If a shortcut doesn't work, check that the menu title is correct.

Shortcut Conflicts

If a Shortcut Doesn't Work

Some shortcuts may conflict with other apps or system shortcuts:

  • Check System Settings → Keyboard → Keyboard Shortcuts for conflicts
  • Disable conflicting system shortcuts if needed
  • Use the custom shortcut feature to assign alternative keys
  • Some third-party apps may intercept shortcuts

Common Conflicts

Shortcut Potential Conflict Solution
⌘⌥D Dock show/hide Disable Dock shortcut or use custom key
⌘H System-wide hide Cannot change (system reserved)
⌃⌘F Full screen System standard, works everywhere

Importing DAW Projects

Analyze which plugins are used in your sessions

Overview

Plugin Reporter can import project files from 17+ popular DAWs and extract a complete list of plugins used in each session. This powerful feature helps you:

  • See which plugins are used in each project
  • Find missing plugins before opening a session
  • Organize projects into playlists
  • Track plugin usage across your entire catalog
  • Plan plugin installations when moving to a new computer

How to Import Projects

Method 1: File Menu

  1. Choose File > Import DAW Project (or press ⌘I)
  2. Navigate to your project file(s)
  3. Select one or multiple project files
  4. Click Open
  5. Wait for parsing to complete
  6. The Playlist sidebar will open automatically showing the imported project(s)
Tip: You can select multiple projects at once to import them in batch. Plugin Reporter will process them in parallel for maximum speed.

Method 2: Drag and Drop

The fastest way to import projects:

  1. Open Finder and locate your DAW project file
  2. Drag the project file(s) directly onto the Plugin Reporter window
  3. The project will be imported automatically
Note: Drag and drop works with all supported file formats. You can even drag entire folders of projects!

Understanding Import Results

What Gets Imported

When you import a DAW project, Plugin Reporter extracts:

  • Project Name - The session/project name
  • Track Names - All audio, MIDI, and instrument tracks
  • Plugin List - Every plugin used in the project
  • Plugin Locations - Which track each plugin is on
  • Plugin Order - Device/slot index in the signal chain
  • Plugin Format - AU, VST, VST3, AAX, etc.
  • Project Metadata - Tempo, sample rate, version (when available)

Plugin Status Indicators

After importing, plugins are marked with status indicators:

Status Meaning Action
✅ Installed Plugin is on your system Ready to use!
❌ Missing Plugin not found on your system Install before opening project
🏷️ Track Name Shows which track(s) use this plugin Helps understand project structure

Working with Imported Projects

Viewing Project Details

After importing, you can:

  • Click on the playlist name in the sidebar to activate the filter
  • See only plugins used in that specific project
  • View which tracks use each plugin (shown in the "Track" column)
  • Identify missing plugins that need to be installed

Multiple Project Selection

Select multiple playlists to see plugins used across all selected projects:

  1. Hold ⌘ while clicking playlist names
  2. Plugin Reporter will show plugins from all selected projects
  3. Missing plugins will be highlighted in red

Editing Playlist Metadata

Add context to your imported projects:

  1. Right-click on a playlist name
  2. Choose Edit Metadata
  3. Add notes, tags, or change the display name
  4. Set a color for easy visual identification

Finding Missing Plugins

One of the most valuable features when importing projects is identifying missing plugins before you open the session in your DAW.

Viewing Missing Plugins

  1. Import your project
  2. Select the playlist from the sidebar
  3. Missing plugins appear in red with a ❌ icon
  4. The "Track" column shows which tracks need these plugins

Creating a Missing Plugin Report

Export a list of missing plugins to install:

  1. Filter to show only the project playlist
  2. Choose File > Export
  3. Select CSV or PDF format
  4. Use this list to install missing plugins before opening your project
Pro Tip: Before migrating to a new computer, import all your projects into Plugin Reporter, export the complete plugin list, and use it as a checklist when installing plugins on your new system.

Playlist Management

Organizing Playlists

Keep your imported projects organized:

  • Rename - Right-click and choose "Rename Playlist"
  • Delete - Remove playlists you no longer need
  • Duplicate - Create variants of existing playlists
  • Color Code - Assign colors to playlists for visual organization
  • Add Tags - Tag playlists by client, genre, or status

Custom Playlists

You can also create manual playlists:

  1. Choose Playlist > New Custom Playlist
  2. Name your playlist (e.g., "Mix Bus Chains", "Vocal Plugins")
  3. Drag and drop plugins from the main table into your playlist
  4. Or select plugins and choose "Add to Playlist"

Batch Importing

Import an entire folder of projects at once:

  1. Choose File > Import DAW Project
  2. Hold ⌘A to select all files in a folder
  3. Or drag an entire folder onto Plugin Reporter
  4. All supported project files will be imported
  5. Progress is shown in the status bar
Performance Note: Plugin Reporter processes multiple projects in parallel for maximum speed. Importing 16 projects takes about the same time as importing one!

Export Format Support

Pro Tools Session Text Export

If you have a Pro Tools session (.ptx), you can also export the session info as text:

  1. Open the session in Pro Tools
  2. Choose File > Export > Session Info as Text
  3. Save as a .txt file
  4. Import the .txt file into Plugin Reporter

Text exports provide more detailed information than binary .ptx files.

Logic Pro Alternatives

For Logic Pro projects, you can also use:

  • .logicx - Standard Logic project package
  • .band - GarageBand projects (compatible)

Troubleshooting Import Issues

Project Won't Import

If a project file won't import:

  • Verify the file extension is supported (see table above)
  • Check that the file isn't corrupted (try opening in the DAW first)
  • For package formats (.logicx, .band), make sure the package is complete
  • Check Console.app for detailed error messages

Missing Plugin Information

If plugins aren't detected:

  • Some DAW formats have limited plugin metadata
  • Binary formats may not store all plugin details
  • Try exporting as text/XML if your DAW supports it

Slow Imports

If importing is slow:

  • Very large projects (100+ tracks) may take a few seconds
  • Binary formats are slower to parse than text/XML
  • This is normal - batch importing still benefits from parallel processing

Best Practices

Tips for Maximum Efficiency

  • Import all your projects to build a complete plugin usage database
  • Use playlists to organize projects by client, genre, or date
  • Export missing plugin lists before opening old projects
  • Tag playlists for easy filtering (e.g., "Active", "Archived", "Client Work")
  • Create custom playlists of your most-used plugins per genre
  • Regularly backup your playlist data using Archive & Restore

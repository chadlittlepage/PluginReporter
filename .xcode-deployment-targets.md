# Xcode Deployment Target Configuration

## IMPORTANT: Update Deployment Targets

Before App Store submission, update deployment targets in Xcode:

### Steps to Update:

1. Open `PluginReporter.xcodeproj` in Xcode
2. Select the project in the navigator (blue icon at top)
3. For each target (PR MAC, PR iPAD, PR iPHONE):

   **For iOS/iPadOS targets:**
   - Click on the target name
   - Go to "Build Settings" tab
   - Search for "iOS Deployment Target"
   - Change from any value to: **17.0**
   - Reason: iOS 17.0+ required for Privacy Manifest features

   **For macOS target:**
   - Already set to 13.0 (correct)
   - No changes needed

4. Clean build folder: Product → Clean Build Folder (Shift+Cmd+K)
5. Rebuild: Product → Build (Cmd+B)

### Why 17.0?

- Privacy Manifest features introduced in iOS 17
- App uses Privacy Manifest declarations
- Ensures compatibility with latest privacy requirements
- Still supports 95%+ of active iOS devices

### Verification:

After changing, verify in Build Settings:
```
IPHONEOS_DEPLOYMENT_TARGET = 17.0
```

## v001 - October 4, 2025

### Features
- **macOS App**: Full plugin scanner with table view, filtering, sorting, and export
- **iOS App**: Mobile interface with plugin list, search, filtering, and export
- **Multi-platform**: Shared codebase supporting both macOS and iOS

### Export Formats
- CSV export
- PDF export
- HTML export
- JSON export

### Key Features
- Plugin scanning from standard macOS audio plugin directories
- Support for AU, VST, VST3, AAX, CLAP formats
- Obsolete plugin detection
- Cloud sync capabilities
- Search and filter functionality
- Statistics and bar graph visualizations
- Consolidated plugin view (groups plugins by name/publisher)

### iOS Specific
- Touch-optimized interface
- ShareSheet integration for exports
- Dropdown menu with clear buttons
- Format badges matching bar graph colors
- Responsive design

### macOS Specific
- Native table view with sorting
- Sidebar filtering
- Export manager with multiple formats
- Plugin detail views
